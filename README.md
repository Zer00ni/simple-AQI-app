# Aplikasi Monitoring kualitas udara berbasis mikrokontroler esp32

Aplikasi Android yang dikembangkan sebagai bagian dari tugas akhir/skripsi untuk memonitoring dan mengkondisikan kualitas udara secara real-time.

## 🚀 Fitur Utama
* **Monitoring Real-time:** Menampilkan data dari sensor mq7, mq135, PMS5003, BME280 secara instan menggunakan Firebase.
* **Kontrol Perangkat:** Fitur untuk menyalakan/mematikan Exhaust Fan secara otomatis maupun manual.
* **History Data:** Menyimpan dan menampilkan riwayat data dalam bentuk List.

## 🛠️ Tech Stack
* **Language:** Kotlin
* **UI:** Jetpack Compose
* **Database:** Firebase Realtime Database
* **Architecture:** MVVM (Model-View-ViewModel)

## ⚙️ Cara Menjalankan
1. Clone repository ini.
2. Tambahkan file `google-services.json` milik Anda ke dalam folder `/app`.
3. Build dan Run menggunakan Android Studio.
